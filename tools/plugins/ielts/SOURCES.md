# 资料来源

- `words.csv`：取自 ECDICT（https://github.com/skywind3000/ECDICT ，MIT 许可证，Copyright (c) Linwei）中标了 ielts 的词，去掉了最常见的 900 个基础词，按词频排序。
- `patterns.json`：写作句型和例句，TWIN 自己编写。
- 更多阅读题：点“备阅读题”时由你在设置里接的 AI 现写文章和题目（含中文解析），存在你的知识库里，不来自任何真题。
- `reading.json`：42 篇阅读文章和 252 道题（每篇 200–250 词，比真题短，方便零碎时间做），TWIN 自己编写的原创内容，按雅思学术类的题型（判断、标题配对、信息配对、选择、填空）和设陷阱的方式出题，不来自任何真题。
- `synonyms.csv`：阅读常见的同义替换，TWIN 自己整理。
